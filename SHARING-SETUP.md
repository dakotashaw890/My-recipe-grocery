# Sharing recipes (links and other families)

Run **sharing-setup.sql** once: Supabase → **SQL Editor → New query** → paste the whole file → **Run**.

That turns on:
- **Short links** (`…/?r=K7QM2XPA`). Without it, links still work but are long, because the whole recipe is packed into the link.
- **Send to another family:** each family gets a public *share code* (Settings → Help). It is NOT the join code: it only lets other families send you recipes, which wait in your inbox on the Home screen.

Check: **Settings → Setup check** shows ✓ *Sharing recipes*.
