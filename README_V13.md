# Version 13 — Smart Pantry

Back up your app before updating. Upload the five website files to GitHub; README is for reference.

New: Have in Pantry per shopping item, shopping quantities reduced by compatible pantry stock, scan-to-pantry confirmation with catalog matching, cooked-meal deduction preview and Undo last cooked meal. Pantry quantities are fractional preferred packages (1 = one preferred package). Recipe selection does not consume stock.

Limits: Existing pantry numbers are interpreted as preferred package counts; review them before use. Ingredients without compatible package units cannot be automatically deducted. Scanning requires a browser with BarcodeDetector support and a product recognized by Open Food Facts; manual barcode entry remains available. Cooking uses selected/planned recipe servings. Sync conflict handling is unchanged from V12; avoid simultaneous edits on both devices.

After installation, check your existing pantry quantities, shopping list and recipes before scanning or cooking.
